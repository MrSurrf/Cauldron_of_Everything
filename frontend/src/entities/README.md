# Entities

Здесь находятся общие предметные сущности, используемые страницами и несколькими
инструментами: существа энциклопедии, а в будущем пользователь, кампания,
участник и персонаж.

`base/` задаёт стабильный ссылочный контракт `EntityReference`. Предметный
модуль `creature/` содержит сериализуемую модель, временный mock-repository и
несколько чистых React-представлений одной модели. Представления не читают URL,
не загружают данные и не зависят от workspace или drag-and-drop.

Сущность выделяется в этот слой, когда она имеет собственную идентичность и
должна одинаково использоваться в нескольких контекстах.

Развёрнутый статблок поддерживает `CreatureSection.entries`: типизированные
особенности с атакой, уроном, спасброском цели, дальностью и эффектами.
`CreatureFeatureSections` показывает их карточками или строками действий.
В моковом Тараске эти данные находятся в `mockTarrasqueFeatures.ts`.
Броски используют существующий `rollDiceExpression`, а спасбросок цели
запрашивает её собственный модификатор и сравнивает результат со сложностью.

Пока структурированные записи подключены к моковому представлению.
Секции реального API продолжают использовать `html` через `RichContent`;
адаптация API к `entries` — отдельный последующий этап. Демонстрация
действий логова и перезарядки находится в Storybook у `CreatureFeatureSections`.
