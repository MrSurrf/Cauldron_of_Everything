# Entities

Здесь находятся общие предметные сущности, используемые страницами и несколькими
инструментами: существа энциклопедии, а в будущем пользователь, кампания,
участник и персонаж.

`base/` задаёт стабильный ссылочный контракт `EntityReference`. Предметный
модуль `creature/` содержит сериализуемую модель, временный mock-repository и
несколько чистых React-представлений одной модели. Представления не читают URL,
не загружают данные и не зависят от workspace или drag-and-drop.

Сущность выделяется в этот слой, когда она имеет собственную идентичность и
должна одинаково использоваться в нескольких контекстах.
