# Страница класса

`ClassFullView` показывает класс из API энциклопедии. Публичный маршрут —
`/encyclopedia/class/:slug`; старые `/encyclopedia/entry/:id` также используют
это представление, если `entity_type === 'class'`.

Данные загружаются через общий авторизованный клиент энциклопедии: поиск
по `type=class&slug=…`, затем подробная запись по найденному ID. В компоненте
нет вручную заполненных правил отдельных классов.

`toClassEntity` выполняется в браузере и разбирает `content_html` через
`DOMParser`. Таблицы превращаются в семантическую модель с `rowspan` и
`colspan`, заголовки и `details` — в дерево разделов с устойчивыми якорями.
Таблица со строками уровней 1–20 показывается отдельно как развитие класса.
Остальные таблицы остаются в своих разделах. Исходные скрипты, обработчики,
меню и управляющие элементы сторонней страницы не переносятся.

`data.sections`, `data.subclasses`, `data.tables` и `data.interactive_blocks`
дополняют HTML без повторного вывода совпадающих материалов. Если доступен
только `content_text`, показывается текст: отсутствующие правила и таблицы
не восстанавливаются по догадкам.

Браузерные проверки, включая API-маршруты:

```bash
npx vitest run --config src/entities/character-class/vitest.browser.config.ts
```

Данные в `testing/` синтетические и используются только для проверок.
