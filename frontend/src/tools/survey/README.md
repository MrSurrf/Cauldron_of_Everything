# Инструмент «Опросник»

Этот каталог содержит существующий рабочий опросник, отделённый от новой
архитектуры фронтенда.

## Границы модуля

- Публичная точка входа — `index.ts`.
- Backend-интеграция остаётся в `api.ts`.
- Страницы и стили опросника находятся в `pages/`.
- Типы и конфигурации находятся в `surveys/`.
- Данные экрана результатов находятся в `results/`.
- Публичные изображения находятся в `public/tools/survey/`.

Новый код приложения не должен импортировать внутренние файлы этого каталога
напрямую. До отдельного рефакторинга модуль подключается целиком через
`SurveyApp`.
