# Мой стол

Минимальное пространство кампании: `/my-table` (меню «Мой стол»).
Схемы, узлы существ и связи на холсте `@xyflow/react`.

- Перетащите существо из бестиария на холст или нажмите «+» рядом с ним.
- Соедините правую точку одного узла с левой точкой другого.
- Нажатие на узел открывает существующую `CreatureCompactCard` справа.
- Delete/Backspace удаляет выбранные узлы и связи.
- Создавайте схемы слева и переключайтесь между ними.

Поиск и карточки используют публичный API `entities/creature`, общий
`CreatureEntity` и существующие компоненты `CreatureReference` и
`CreatureCompactCard`. Нужен доступный сервер энциклопедии.

Сохранение синхронное в `localStorage`, ключ `cauldron.campaign-table.v1`.
Хранятся версия формата, активная схема, названия схем, ссылки на существ
(ID, slug, имя), координаты узлов, связи и положение/масштаб холста.
Статблоки не копируются в сохранение и загружаются из Entity API для узлов и боковой карточки.
У одного существа может быть несколько независимых узлов.

Сохранение относится к браузеру и origin, не синхронизируется между
устройствами или учётными записями. При ошибке записи UI сообщает об этом.
Повреждённое или неизвестное сохранение автоматически не перезаписывается.

Совместное редактирование, серверное хранение, публичные права и дополнительные
инструменты в прототип не входят.

Проверка пользовательского сценария: `node scripts/test-campaign-table.mjs`
при запущенном Vite на `127.0.0.1:5173` (либо `TABLE_TEST_URL`). Проверка
использует изолированный Chromium и тестовые HTTP-ответы без записи в реальную БД.
