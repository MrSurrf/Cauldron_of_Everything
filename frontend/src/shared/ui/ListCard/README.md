# ListCard

Компактное представление списка, без собственного обработчика навигации.
Помещайте его внутрь `Link` или `button`, чтобы сохранить семантику и управление с клавиатуры.

`appearance="default"` сохраняет существующие списки библиотеки без изменений.
`appearance="navigation"` — спокойная кнопка перехода с обычной рамкой, иконкой `icon`, названием и описанием в `tags`.
Навигационный вид не использует `Panel` или акцентный `Button`; декоративная подложка группы задаётся отдельно.

Цвета берутся из дизайн-токенов. Минимальную высоту и отступы можно уточнить переменными
`--list-card-min-height`, `--list-card-padding`, `--list-card-padding-end`,
`--list-card-background` и `--list-card-border` без копирования CSS компонента.
