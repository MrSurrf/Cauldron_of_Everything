# Shared UI

Здесь размещаются общие примитивы интерфейса. Сейчас реализован `Button` с
вариантами `primary` и `secondary`. Далее здесь появятся `IconButton`, `Panel`,
`Input`, `FormField`, `ScrollArea`, `Badge`, `Tabs`, `Tooltip` и другие
компоненты дизайн-системы.

Каждый компонент получает собственный каталог, стили и публичный `index.ts`.
Предметные компоненты конкретного инструмента в этот слой не переносятся.
