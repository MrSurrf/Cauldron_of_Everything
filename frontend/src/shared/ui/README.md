# Shared UI

Для короткого однострочного ввода используется `TextInput`, для длинного
текста с переносами и нашим скроллбаром — `TextArea`. Оба компонента являются
законченными полями: поддерживают label, подсказку, ошибку, иконку и счётчик
символов.

Здесь размещаются общие примитивы интерфейса. Сейчас реализованы `Button` с
вариантами `primary` и `secondary`, масштабируемая подложка `IconFrame`,
`MenuButton` для постоянного главного меню, контейнер `Panel` с нейтральным и
будущим drag-and-drop вариантами,
компактный `ScrollBar` в двух ориентациях, универсальный `ScrollArea`,
`TextInput` и `TextArea`. Для плотных интерфейсов доступны размеры `Button`,
отдельный `IconButton`, portal-подсказка `Tooltip` и поисковый `Combobox`.
Далее здесь появятся `Badge`, `Tabs` и другие компоненты дизайн-системы.

Каждый компонент получает собственный каталог, стили и публичный `index.ts`.
Предметные компоненты конкретного инструмента в этот слой не переносятся.
Общие рамки, ARIA-связи и другие детали реализации полей находятся в
`shared/ui/internal` и не входят в публичный API инструментов.
