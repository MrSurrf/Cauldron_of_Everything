# Shared UI

Текстовые поля формы создаются через `FormField`: однострочный вариант
используется по умолчанию, а `as="textarea"` включает переносы и вертикальную
прокрутку. `TextInput` и `TextArea` сохранены как низкоуровневые совместимые
контролы.

Здесь размещаются общие примитивы интерфейса. Сейчас реализованы `Button` с
вариантами `primary` и `secondary`, масштабируемая подложка `IconFrame`,
`MenuButton` для постоянного главного меню, контейнер `Panel` с нейтральным и
будущим drag-and-drop вариантами,
компактный `ScrollBar` в двух ориентациях и `FormField` с однострочным и
многострочным режимами, подписью, ошибкой и счётчиком символов. Далее здесь
появятся `IconButton`, `ScrollArea`, `Badge`, `Tabs`, `Tooltip` и другие
компоненты дизайн-системы.

Каждый компонент получает собственный каталог, стили и публичный `index.ts`.
Предметные компоненты конкретного инструмента в этот слой не переносятся.
