# Shared UI

Текстовые поля разделены по назначению: `TextInput` принимает короткое значение
в одну строку, а `TextArea` поддерживает переносы и вертикальную прокрутку
объёмных текстов.

Здесь размещаются общие примитивы интерфейса. Сейчас реализованы `Button` с
вариантами `primary` и `secondary`, `MenuButton` для постоянного главного меню,
компактный `ScrollBar` в двух ориентациях и `TextInput` с поддержкой SVG-иконки.
Далее здесь появятся `IconButton`, `Panel`, `FormField`, `ScrollArea`, `Badge`,
`Tabs`, `Tooltip` и другие
компоненты дизайн-системы.

Каждый компонент получает собственный каталог, стили и публичный `index.ts`.
Предметные компоненты конкретного инструмента в этот слой не переносятся.
