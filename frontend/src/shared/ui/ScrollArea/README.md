# ScrollArea

Универсальная оболочка для прокрутки произвольного содержимого: секций
инструментов, списков, панелей и будущего workspace. Видимые полосы используют
готовый `ScrollBar`, поэтому стрелки, тонкий трек, белый ромб, focus и
forced-colors режим совпадают с остальной дизайн-системой.

```tsx
<Panel padding="none">
  <ScrollArea
    aria-label="Инвентарь персонажа"
    rootStyle={{ height: '100%' }}
  >
    <Inventory />
  </ScrollArea>
</Panel>
```

Поддерживаются `vertical`, `horizontal` и `both`. Нативные полосы viewport
скрыты, но сама прокрутка остаётся браузерной: работают колесо мыши, тачпад,
touch, клавиатура, `scrollIntoView()` и программная установка `scrollTop` /
`scrollLeft`. Кастомная полоса появляется только при реальном переполнении.

`ref`, `id`, `className`, `style`, обработчики и ARIA-свойства относятся к
настоящему прокручиваемому viewport. `rootClassName` и `rootStyle` относятся к
grid-оболочке, которая размещает полосы рядом с содержимым.
`contentClassName` оформляет внутренний измеряемый контейнер.

```tsx
const viewportRef = useRef<HTMLDivElement>(null)

<ScrollArea
  ref={viewportRef}
  rootClassName={styles.area}
  contentClassName={styles.content}
>
  {children}
</ScrollArea>
```

Если передано `aria-label` или `aria-labelledby`, viewport автоматически
получает `role="region"` и `tabIndex={0}`: область объявляется скринридером и
прокручивается с клавиатуры. Эти значения можно явно переопределить. Ползунок
`ScrollBar` также остаётся отдельным доступным клавиатурным контролом.

## Производительность

Измерение вынесено в общий внутренний `ScrollSync`, который также используется
`TextArea`. События scroll объединяются через `requestAnimationFrame`, на
каждом кадре читается только позиция, а полная геометрия пересчитывается после
resize, изменения содержимого, значения поля или form reset. Состояние
скроллбаров изолировано от содержимого, поэтому тяжёлое дерево внутри
`ScrollArea` не перерисовывается на каждый пиксель прокрутки.

`TextArea` не оборачивается в `ScrollArea`: нативный `<textarea>` остаётся
собственным viewport, но использует тот же контроллер синхронизации.
