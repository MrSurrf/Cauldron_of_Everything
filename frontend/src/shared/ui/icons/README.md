# Icons

Общие векторные иконки интерфейса. Импортируйте их через публичный API
`shared/ui`, чтобы один и тот же знак использовался во всех инструментах.

- `EditIcon` — стандартное действие редактирования.
- `TrashIcon` — стандартное действие удаления.
- `AttunementIcon` и `EquippedIcon` — состояния предмета.
- `DiceIcon` — кости d4, d6, d8, d10, d12 и d20 для бросков и пулов костей.
- `SavingThrowIcon` — обозначение владения спасброском.

Иконки наследуют `currentColor`, а подпись действия задаётся на кнопке или
чекбоксе через `aria-label`. SVG-исходники хранятся только в `icons/assets`.
