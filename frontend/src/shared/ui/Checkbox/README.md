# Checkbox

Компактный нативный флажок с подписью и необязательным описанием. Визуально
использует общий `SelectionMarker`: пустой круг для выключенного состояния и
фиолетовую светящуюся точку для включённого — тот же маркер, что в навыках.

```tsx
<Checkbox
  label="Экипировано"
  checked={equipped}
  onCheckedChange={setEquipped}
/>
```

Для неуправляемого режима используйте `defaultChecked`. Нативные атрибуты
поля, включая `name`, `required`, `disabled` и `aria-*`, передаются в `input`.
Состояние `indeterminate` задаётся отдельно и отражается как
`aria-checked="mixed"`. Компонент поддерживает клавиатуру и нативный сброс
формы; при отсутствии видимой подписи сохраняется увеличенная область нажатия.

Для компактного icon-only флага передайте `indicator`. Он заменит стандартный
круглый маркер, а не будет показан рядом с ним. У такого варианта обязательно
должен быть `aria-label`; нативное переключение мышью и клавишей Space
сохраняется.

```tsx
<Checkbox
  aria-label="Надето"
  checked={equipped}
  indicator={<EquippedIcon />}
  onCheckedChange={setEquipped}
/>
```

Для любого бинарного выбора в инструментах и страницах импортируйте только
этот компонент из `shared/ui`. Не создавайте локальный `input[type='checkbox']`
и не используйте декоративный `SelectionMarker` как интерактивный контрол.

`className` применяется к самому `input`, а `rootClassName` — к внешней
подписи.
