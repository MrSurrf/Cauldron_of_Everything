# SegmentedControl

Компактный одиночный выбор между несколькими короткими вариантами.

```tsx
<SegmentedControl
  aria-label="Редакция правил"
  options={[
    { value: '2014', label: '2014' },
    { value: '2024', label: '2024' },
  ]}
  value={ruleset}
  onValueChange={setRuleset}
/>
```

Компонент работает в управляемом (`value`) и неуправляемом (`defaultValue`)
режимах. Стрелки перемещают выбор с циклическим переходом, `Home` и `End`
выбирают первый и последний доступные варианты. Для отправки значения обычной
HTML-формой передайте `name`.

Группе всегда нужна доступная подпись через `aria-label` или
`aria-labelledby`. Значения вариантов должны быть уникальными.
