# TextInput

Законченное однострочное поле для коротких значений: поиска, логина, имени
персонажа, адреса и похожих данных. Внутри всегда остаётся нативный `<input>`,
поэтому компонент поддерживает стандартные атрибуты формы, браузерную
валидацию, автозаполнение и клавиатурное управление.

Для многострочного текста и внутренней прокрутки используется отдельный
`TextArea`.

## Базовое использование

```tsx
<TextInput
  label={'Имя персонажа'}
  name={'characterName'}
  hint={'Это имя увидят остальные игроки.'}
  required={true}
/>
```

`label` связывается с input через `for`/`id`. `hint`, `error` и счётчик
автоматически добавляются в ARIA-описание поля. Наличие `error`, `invalid` или
истинного `aria-invalid` включает состояние ошибки.

Если видимый `label` не нужен, компоненту всё равно следует передать
доступное имя:

```tsx
<TextInput
  aria-label={'Поиск по сайту'}
  icon={<SearchIcon />}
  placeholder={'Найти материал...'}
  type={'search'}
/>
```

Без `label` placeholder по умолчанию равен `Ваш текст...`. Он не исчезает от
одного фокуса и скрывается только после появления первого символа в нативном
input. При наличии плавающего `label` placeholder визуально скрывается, чтобы
два текста не накладывались друг на друга.

## Ошибка и счётчик

```tsx
<TextInput
  label={'Короткое имя'}
  error={'Введите имя персонажа.'}
  maxLength={24}
  showCharacterCount={true}
/>
```

`maxLength` остаётся нативным ограничением браузера. `showCharacterCount`
показывает текущее количество символов и, если задан `maxLength`, лимит в
формате `7 / 24`. Счётчик работает и с `value`, и с `defaultValue`, а после
нативного сброса формы возвращается к длине исходного значения.
Если controlled-`value` программно превышает лимит, поле помечается как
невалидное.

## Иконка и классы

Переданная через `icon` SVG-иконка располагается справа, наследует цвет поля,
использует режим наложения `screen` и скрыта от accessibility tree как
декоративная. У поля нет отдельного hover-эффекта; focus-состояние сохраняется.

Точки расширения разделены по уровням:

- `fieldClassName` — внешний контейнер с label и supporting text;
- `rootClassName` — декоративная рамка;
- `className` — нативный `<input>`.

Все остальные нативные свойства input (`name`, `value`, `defaultValue`,
`onChange`, `onInput`, `autoComplete`, `form`, `pattern` и другие)
пробрасываются на контрол. `ref` также указывает непосредственно на нативный
`HTMLInputElement`.
