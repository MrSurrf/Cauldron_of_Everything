# TextInput

Однострочное поле для поиска, логина и других коротких значений. Компонент
использует нативный `<input>` и не поддерживает переносы строк или внутренний
скролл. Для объёмного текста используется отдельный `TextArea`.

Текстовое поле в цветах `secondary`-кнопки. Внешняя рамка имеет толщину `1px`,
углы срезаны прямыми диагоналями, внутри сохраняется дополнительная блеклая
обводка. Угловых ромбов у поля нет.

По умолчанию отображается нативный placeholder `Ваш текст...`. Он остаётся
видимым при фокусе и исчезает только после ввода первого символа. Значение
placeholder можно заменить обычным пропом.

```tsx
<TextInput aria-label={'Описание'} />

<TextInput
  aria-label={'Поиск'}
  placeholder={'Найти материал...'}
  icon={<SearchIcon />}
/>
```

Переданный через `icon` SVG располагается справа, использует цвет поля и режим
наложения `screen`. Hover-эффекта нет; для клавиатуры и ввода сохраняется
focus-состояние. `className` применяется к нативному `input`, а
`rootClassName` — к внешней рамке компонента.
