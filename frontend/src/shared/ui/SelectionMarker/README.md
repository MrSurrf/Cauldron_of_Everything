# SelectionMarker

Единый визуальный маркер выбора для чекбоксов, навыков и связанных счётчиков.
Состояния `unchecked` и `checked` соответствуют пустому кругу и светящейся
точке; `mixed` показывает частичный выбор, а `diamond` используется составными
контролами с дополнительным уровнем состояния.

Компонент отвечает только за вид и не интерактивен. Для обычного бинарного
переключателя используй `Checkbox`, который уже включает этот маркер и
сохраняет нативную семантику `input[type='checkbox']`.
