# Popover

Интерактивная панель рядом с кнопкой или другим доступным
триггером.

```tsx
<Popover
  aria-label="Настройки формулы"
  content={<FormulaSettings />}
  open={open}
  onOpenChange={setOpen}
>
  <IconButton aria-label="Настроить формулу" />
</Popover>
```

Для неуправляемого режима используйте `defaultOpen`. Компонент закрывается по
`Escape` и при нажатии за пределами триггера и панели. Фокус после `Escape`
возвращается на триггер; при открытии он переходит к первому доступному
элементу содержимого. Панель рендерится в portal и автоматически меняет сторону,
когда на выбранном направлении недостаточно места.

Триггер должен быть интерактивным элементом с доступным именем. Самой панели
нужно имя через `aria-label` или `aria-labelledby`. По умолчанию панель немодальная:
он не блокирует остальную страницу и не удерживает фокус внутри. `Shift+Tab`
из первого контрола возвращает фокус к триггеру, а `Tab` из последнего закрывает
панель и продолжает обход со следующего элемента после триггера.

`modal` включает нативный `<dialog>`: затемняет фон, блокирует остальные элементы
страницы и удерживает Tab/Shift+Tab внутри окна. Клик по затемнению закрывает окно
без нажатия на элемент под ним. Escape также закрывает окно и возвращает фокус.
