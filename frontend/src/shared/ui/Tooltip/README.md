# Tooltip

Короткая контекстная подсказка для компактных действий и незнакомых
обозначений.

```tsx
<Tooltip content="Добавить предмет" placement="top">
  <IconButton
    aria-label="Добавить предмет"
    icon={<PlusIcon />}
  />
</Tooltip>
```

- открывается по наведению и при получении фокуса с клавиатуры;
- закрывается по `Escape`;
- рендерится через portal и не обрезается контейнерами;
- автоматически меняет сторону, если у края экрана недостаточно места;
- сохраняет обработчики событий и `ref` дочернего элемента.

Portal создаётся в ближайшем `[data-overlay-root]` или в `document.body`.
При необходимости контейнер можно задать явно через `portalContainer`.
Если локальный контейнер создаёт собственную систему координат через
`transform`, `filter` или `contain`, компонент безопасно использует
`document.body`, чтобы подсказка не смещалась относительно цели.

Подсказка не заменяет доступное имя. У кнопки только с иконкой всё равно
должен быть собственный `aria-label`.
