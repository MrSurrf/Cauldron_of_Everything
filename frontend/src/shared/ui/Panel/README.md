# Panel

Нейтральный статичный контейнер дизайн-системы. `Panel` использует прежнюю
тёмную градиентную поверхность из `--color-surface-default` и
`--color-background`, тонкий контур `--color-content-border` и более блеклую
внутреннюю рамку. Углы повторяют мягкие внутренние срезы кнопок, но кнопочные
угловые шейпы, hover и active-эффекты отсутствуют.

```tsx
import { Panel } from '../shared/ui'

<Panel>
  <h2>Персонаж</h2>
  <p>Основные параметры персонажа.</p>
</Panel>
```

Свойство `padding` управляет только внутренним отступом:

- `normal` — обычный отступ, используется по умолчанию;
- `compact` — более плотное содержимое;
- `none` — без композиционного отступа, например для будущего canvas или
  `ScrollArea`; минимальный зазор до внутренней рамки всё равно сохраняется.

`Panel` остаётся обычным `div` и не получает роль или фокус автоматически.
Если блок должен быть отдельным регионом страницы, передай ему `role='region'`
и доступное имя через `aria-label` или `aria-labelledby`.

Скролл не встраивается в панель. Существующий `ScrollBar` является отдельным
контролом, а контейнером прокрутки позже станет `ScrollArea`.

Рамка рисуется отдельными декоративными слоями и не обрезает содержимое.
Благодаря этому focus-ring, dropdown, tooltip и drag-preview могут выходить за
границы панели.
