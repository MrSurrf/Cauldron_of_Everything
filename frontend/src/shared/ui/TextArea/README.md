# TextArea

Законченное публичное многострочное поле дизайн-системы. `TextArea` объединяет
нативный `<textarea>`, диагональную рамку, плавающий `label`, подсказку, ошибку,
счётчик символов, опциональную иконку и общий кастомный скроллбар.

```tsx
<TextArea
  label={'История персонажа'}
  hint={'Кратко опишите прошлое героя.'}
  maxLength={500}
  rows={8}
  showCharacterCount={true}
/>
```

## Подпись и состояния

- `label` связывается с нативным контролом через `for`/`id` и служит его
  доступным именем;
- `hint` показывается под рамкой и добавляется в `aria-describedby`;
- `error` заменяет подсказку, включает невалидное состояние и связывается с
  контролом через `aria-errormessage`;
- `invalid` включает ошибочное состояние без обязательного сообщения;
- `required`, `disabled` и `readOnly` одновременно управляют нативным
  `<textarea>` и внешним видом поля;
- пользовательские `aria-describedby`, `aria-errormessage` и `aria-invalid`
  сохраняются и объединяются с семантикой оболочки.

При наличии `label` нативный placeholder визуально скрыт, чтобы тексты не
накладывались. Без `label` placeholder по умолчанию равен `Ваш текст...`, не
исчезает от одного фокуса и скрывается только после ввода первого символа.

## Счётчик и формы

`showCharacterCount` добавляет счётчик в правый нижний угол. Если передан
`maxLength`, формат счётчика — `текущее / максимум`, а ограничение остаётся
нативным ограничением textarea. Для controlled-поля счётчик вычисляется из
`value`, для uncontrolled — обновляется по событию `input`. Controlled-поле,
значение которого программно превышает лимит, помечается как невалидное.

Нативный `form.reset()` возвращает uncontrolled-значение, счётчик и положение
скроллбара к исходному состоянию. Поддерживаются как вложение в `<form>`, так и
внешняя привязка через атрибут `form`.

## Прокрутка

Для прокрутки используется общий `ScrollBar`, синхронизированный через
`ScrollSync`. Нативная полоса скрыта, но колесо, тачпад, клавиатура, caret,
выделение текста и `scrollIntoView()` продолжают работать с настоящим
`<textarea>`. Защитные слои не позволяют прокручиваемым строкам рисоваться
поверх верхней и нижней части рамки.

Поле переносит строки, использует `rows={6}` по умолчанию и не поддерживает
rich-text форматирование. Нативный resize отключён стилями, чтобы не ломать
диагональные срезы рамки.

## Иконка, классы и ref

SVG, переданный через `icon`, располагается справа сверху, наследует цвет поля
и использует режим наложения `screen`.

- `fieldClassName` применяется к полной структуре поля вместе с сообщением;
- `rootClassName` применяется к декоративной рамке;
- `className` применяется к нативному `<textarea>`.

Все остальные нативные свойства textarea (`name`, `value`, `defaultValue`,
`onChange`, `onInput`, `autoComplete`, `form`, `wrap` и другие) пробрасываются
на контрол. Публичный `ref` всегда указывает на нативный
`HTMLTextAreaElement`.
