# TextArea

Для прокрутки используется общий компонент `ScrollBar`, синхронизированный с
позицией `<textarea>`. Нативная полоса скрыта, но прокрутка колёсиком, тачпадом
и клавиатурой самого текстового поля сохраняется.

Многострочное поле для описаний, заметок и другого объёмного обычного текста.
Использует нативный `<textarea>`, переносит строки и при переполнении показывает
компактный вертикальный скроллбар. Форматирование текста пока не поддерживается.

По умолчанию поле занимает шесть строк. Высоту можно менять через `rows`, а
размер снаружи — через `rootClassName`. Нативный resize отключён, чтобы не
ломать диагональные срезы рамки.

```tsx
<TextArea aria-label={'Описание персонажа'} />

<TextArea
  aria-label={'Заметки'}
  icon={<NotesIcon />}
  rows={10}
/>
```

`className` применяется к самому `<textarea>`, а `rootClassName` — к внешней
рамке. SVG-иконка располагается справа сверху, использует цвет поля и режим
наложения `screen`.
