# TextArea

Для прокрутки используется общий компонент `ScrollBar`, синхронизированный с
позицией `<textarea>`. Нативная полоса скрыта, но прокрутка колёсиком, тачпадом
и клавиатурой самого текстового поля сохраняется. Видимая область текста
ограничена внутренними отступами: промежуточные строки при прокрутке не
рисуются поверх верхней или нижней рамки. Клик по этой защитной области
по-прежнему фокусирует textarea.

Многострочное поле для описаний, заметок и другого объёмного обычного текста.
Использует нативный `<textarea>`, переносит строки и при переполнении показывает
компактный вертикальный скроллбар. Форматирование текста пока не поддерживается.

По умолчанию поле занимает шесть строк. Высоту можно менять через `rows`, а
размер снаружи — через `rootClassName`. Нативный resize отключён, чтобы не
ломать диагональные срезы рамки. У disabled-поля отключается и связанный
кастомный скроллбар. После нативного `form.reset()` состояние скроллбара
пересчитывается вместе со значением поля.

```tsx
<TextArea aria-label={'Описание персонажа'} />

<TextArea
  aria-label={'Заметки'}
  icon={<NotesIcon />}
  rows={10}
/>
```

В составе формы многострочный режим создаётся через единый компонент:

```tsx
<FormField
  as="textarea"
  label="Заметки"
  maxLength={500}
  rows={10}
  showCharacterCount
/>
```

`className` применяется к самому `<textarea>`, а `rootClassName` — к внешней
рамке. SVG-иконка располагается справа сверху, использует цвет поля и режим
наложения `screen`. Прямое использование `TextArea` остаётся доступным для
низкоуровневых сценариев и обратной совместимости.
