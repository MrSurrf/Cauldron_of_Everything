# ScrollBar

Компактный контрол положения прокрутки с вариантами `horizontal` и `vertical`.
По краям находятся небольшие кнопки шага, между ними — тонкий трек и маленький
белый ромб-звёздочка. Все цвета берутся из токенов дизайн-системы.

Внутри используется нативный `input[type='range']`, поэтому доступны drag,
клавиатура и focus-состояние. Значение можно оставить внутренним через
`defaultValue` или контролировать пропами `value` и `onValueChange`.

```tsx
<ScrollBar
  aria-label={'Горизонтальная прокрутка'}
  value={scrollLeft}
  max={maxScrollLeft}
  onValueChange={setScrollLeft}
/>

<ScrollBar
  aria-label={'Вертикальная прокрутка'}
  orientation={'vertical'}
  defaultValue={35}
  style={{ height: '100%' }}
/>
```

Размер задаётся контейнером: горизонтальный вариант занимает доступную ширину,
вертикальный — доступную высоту.
