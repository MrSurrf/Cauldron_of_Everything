# ContentEditor

`ContentEditor` — общий визуальный редактор содержимого. Он предназначен для
заметок, описаний и других полей, где нужны форматирование, списки, ссылки,
броски и структурные блоки. Обычные короткие и многострочные form-control по-
прежнему используют `TextInput` и `TextArea`.

Редактор построен на Lexical, но весь внешний вид задаётся дизайн-токенами
Cauldron of Everything. Пользователь никогда не редактирует Markdown напрямую:
существующие строки разбираются `contentCodec`, отображаются как rich text и
сериализуются обратно в совместимый строковый формат.

Состояния интерфейса взаимоисключающие:

- без выделения виден только контент;
- при выделении компактная панель форматирования появляется рядом с DOM Range;
- при каретке в пустом абзаце появляется меню вставки ресурса, раскрываемого
  раздела или разделителя;
- обе панели рендерятся через portal и не участвуют в размерах поля.

```tsx
<ContentEditor
  accessibleLabel="Описание"
  fill={true}
  showStructureActions={true}
  value={value}
  onValueChange={setValue}
/>
```

Текущий codec оставлен как миграционный слой для данных Character Sheet.
Публичный API редактора не зависит от модели персонажа, поэтому позднее его
можно перевести на версионированный JSON-документ без замены UI-компонента.
