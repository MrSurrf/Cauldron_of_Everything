# Combobox

Одиночный выбор из справочника с поиском.

```tsx
<Combobox
  label="Класс"
  name="classId"
  options={[
    { value: 'fighter', label: 'Воин' },
    { value: 'wizard', label: 'Волшебник' },
  ]}
  onValueChange={(value, option) => {
    console.log(value, option)
  }}
/>
```

Компонент поддерживает:

- управляемые и неуправляемые `value` и `open`;
- фильтрацию по `label` и `keywords`;
- навигацию стрелками, `Home`, `End`, `Enter`, `Escape`;
- `label`, `hint`, `error`, `required`, `disabled`, `readOnly`;
- иконки и краткие описания вариантов;
- portal-позиционирование с автоматическим переносом вверх;
- общий `ScrollArea` для длинных списков;
- отправку выбранного `value` через скрытое поле, если передан `name`;
- восстановление `defaultValue` при нативном `form.reset()`.

При начале редактирования прежний выбор очищается. Текст, который не был
подтверждён выбором варианта, не считается значением и блокирует отправку
формы через native constraint validation.

По умолчанию список рендерится в ближайший `[data-overlay-root]` или в
`document.body`. Для локальной темы или отдельного overlay-слоя можно передать
конкретный DOM-элемент через `portalContainer`.

Значения вариантов должны быть уникальными. Для очень больших серверных
справочников фильтрацию следует выполнять снаружи и передавать уже
подготовленный массив `options`.
