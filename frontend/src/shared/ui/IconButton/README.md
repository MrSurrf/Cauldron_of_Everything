# IconButton

Компактная квадратная кнопка для панелей инструментов и действий, которые
однозначно выражаются иконкой. Она переиспользует `Button`, поэтому варианты,
состояния наведения, нажатия, фокуса и геометрия рамки остаются общими.

```tsx
import {
  IconButton,
  PlaceholderIcon,
} from '../shared/ui'

<IconButton
  aria-label={'Добавить персонажа'}
  icon={<PlaceholderIcon />}
/>

<IconButton
  aria-label={'Сохранение'}
  icon={<PlaceholderIcon />}
  loading
  variant={'primary'}
/>
```

`aria-label` и `icon` обязательны на уровне TypeScript. Доступное имя должно
описывать действие, а не внешний вид иконки. По умолчанию используются
компактный размер `md` и вариант `secondary`; доступны `sm`, `md`, `lg` и оба
варианта обычной кнопки. Во время `loading` иконка заменяется индикатором,
выставляется `aria-busy`, а повторное нажатие блокируется.
