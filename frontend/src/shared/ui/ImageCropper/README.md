# Кадрирование изображений

Общая рамка для редактора статей, портретов персонажей и аватара профиля.
Не импортирует внутренние компоненты инструментов.

```tsx
<ImageCropDialog
  file={pendingFile}
  title="Кадрирование портрета"
  initialAspectRatio={1}
  onConfirm={croppedFile => { save(croppedFile); setPendingFile(null) }}
  onCancel={() => setPendingFile(null)}
/>
```

Без `initialAspectRatio` рамка свободная. Можно менять пропорции, перемещать
рамку, тянуть за восемь ручек и точно настраивать кадр стрелками. Выбор
«Свободно» не сбрасывает текущую область; для сброса есть отдельная кнопка.

Диалог находится в top layer и не обрезается контейнером чарлиста.
Поддерживаются JPEG, PNG и WebP до 5 МБ и 40 мегапикселей. После подтверждения
возвращается новый файл с обрезанными пикселями, размером до 1024 px по длинной
стороне. Отмена не вызывает `onConfirm`; вызывающий компонент закрывает
диалог, убрав его из дерева.
