# IconFrame

Масштабируемая SVG-подложка для иконок. Внешняя фигура, круг и угловой
орнамент повторяют общий референс, а содержимое передаётся через `children`.

```tsx
import { IconFrame } from '../shared/ui'

<IconFrame
  size={160}
  frameColor="var(--palette-purple-300)"
  squareBackgroundColor="var(--color-background)"
  circleBackgroundOpacity={0.1}
>
  <MapIcon />
</IconFrame>
```

Доступные настройки:

- `frameColor` — цвет всех линий рамки и унаследованный цвет центральной иконки;
- `squareBackgroundColor` — фон внутри внешней фигуры;
- `circleBackgroundColor` — отдельный цвет фона круга;
- `circleBackgroundOpacity` — прозрачность фона круга от `0` до `1`;
- `size` — размер всей подложки;
- `contentSize` — размер квадратной области для центральной SVG-иконки;
- `glow` — включает свечение рамки и иконки; по умолчанию `true`.

Если `circleBackgroundColor` не задан, круг использует `frameColor` с
прозрачностью `10%`. SVG-иконки с `fill="currentColor"` автоматически получают
цвет рамки; собственные цвета иконки при этом не переопределяются.

Для отключения свечения достаточно передать `glow={false}`. Цветовые пропсы
должны ссылаться на токены из `shared/styles/tokens.css`, без локальных
HEX-значений.

Рамка не выходит за ширину родителя, а область иконки уменьшается вместе с ней,
даже если `size` и `contentSize` заданы в пикселях. Для плавного адаптива можно
передавать любое корректное CSS-значение размера:

```tsx
<IconFrame
  size="clamp(6rem, 24vw, 15rem)"
  contentSize="42%"
>
  <MapIcon />
</IconFrame>
```

Числовые значения интерпретируются как пиксели. Если `size` и `contentSize`
заданы числами, при вынужденном уменьшении рамки их пропорция сохраняется.
Отрицательные значения ограничиваются нулём, а нечисловые бесконечные размеры
игнорируются.
