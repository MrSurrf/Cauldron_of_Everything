# Подсветка курсора

`CursorLighting` подключает один контроллер на приложение. Он обновляет фон
`main` и `[data-cursor-light-background]`, а также рамки `[data-cursor-reveal]`.

Меняющиеся координаты, активность и `--cursor-background-image` зарегистрированы
через `@property` с `inherits: false`. Готовый градиент тоже нельзя делать
наследуемым: иначе движение мыши пересчитывает стили всего содержимого страницы.
Новый фон, которому нужна подсветка, должен явно иметь
`data-cursor-light-background`.

У `Panel` координаты записываются прямо в декоративный слой
`[data-cursor-reveal-layer]`. Режим `data-cursor-reveal="border"` рисует свет
на собственной границе элемента. В обоих случаях координаты не наследуются
содержимым панели. Контроллер объединяет обновления в один кадр, сначала читает
геометрию и затем записывает только изменившиеся значения.

Наличие `[data-cursor-light-suspended]` временно выключает весь эффект.
Карта кампании ставит этот атрибут на холст при drag и resize нод и снимает
после завершения или отмены жеста. Контроллер сохраняет последнюю позицию
курсора и возобновляет подсветку после снятия блокировки. Touch, reduced motion
и forced colors отключают эффект; уход курсора и потеря фокуса сбрасывают свет.

Проверка: `npx vitest run --config src/shared/ui/CursorLighting/vitest.browser.config.ts`.
Регрессия карты: `node scripts/test-campaign-drag-performance.mjs` при работающем
Vite (`TABLE_TEST_URL` задаёт адрес). Она использует обычный режим анимаций и
проверяет отсутствие записей CSS во время drag и resize.
