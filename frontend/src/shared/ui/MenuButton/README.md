# MenuButton

Пункт постоянного главного меню. В обычном состоянии показывает SVG-иконку и
текст, а при наведении, выборе или раскрытии повторяет оформление `primary`:
градиент, внешнюю и внутреннюю рамки и четыре угловых шейпа.

Если передан `dropdown`, компонент показывает нативный символ `▾` и раскрывает
группу вложенных `MenuButton` по нажатию. Состояние можно оставить внутренним
через `defaultExpanded` или контролировать пропами `expanded` и
`onExpandedChange`. Если `icon` не передан, используется общая временная
SVG-заглушка из `primary`; переданный через `icon` SVG заменяет её. Раскрытая
группа отделяется тонкой рамкой цвета `--color-border-default`.

```tsx
<MenuButton active>
  Главная
</MenuButton>

<MenuButton
  dropdown={
    <>
      <MenuButton>Генератор встреч</MenuButton>
      <MenuButton>Генератор наград</MenuButton>
    </>
  }
>
  Инструменты
</MenuButton>
```
