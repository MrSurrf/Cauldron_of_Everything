# Button

Общая кнопка дизайн-системы. Реализованы два уровня действий:

- `primary` — фиолетовая кнопка с белыми текстом, SVG-иконкой и свечением;
- `secondary` — тёмная кнопка с рамкой без иконки.

```tsx
import { Button } from '../shared/ui'

<Button variant="primary">
  Начать приключение
</Button>

<Button variant="secondary">
  Пройти опрос нулевой сессии
</Button>
```

У `primary` по умолчанию отображается временная SVG-иконка. Переданная через
`icon` SVG-иконка заменяет её и выводится с режимом наложения `screen`. Чтобы
скрыть иконку, передай `icon={null}`. Вариант `tertiary` будет добавлен после
утверждения его визуального референса.

Размеры `sm`, `md` и `lg` соответствуют высотам контролов 32, 40 и 48 px и
предназначены для компактных панелей инструментов и форм. Размер `hero`
сохраняет исходную крупную геометрию и используется по умолчанию, поэтому
существующие вызовы `Button` не меняют внешний вид.

Параметр `decoration` управляет только насыщенностью оформления. `ornate`
сохраняет полную рамку с угловыми элементами, `minimal` оставляет одну тонкую
рамку со срезанными углами, а `bare` предназначен для безрамочных действий
внутри общей панели инструментов. В вариантах `minimal` и `bare` свечение не
используется.

```tsx
<Button size={'sm'} icon={null}>
  Сохранить
</Button>
```
