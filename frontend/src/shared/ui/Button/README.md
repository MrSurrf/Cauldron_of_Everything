# Button

Общая кнопка дизайн-системы. Реализованы два уровня действий:

- `primary` — фиолетовая кнопка с подсветкой и стрелкой;
- `secondary` — тёмная кнопка с рамкой без иконки.

```tsx
import { Button } from '../shared/ui'

<Button variant="primary">
  Начать приключение
</Button>

<Button variant="secondary">
  Пройти опрос нулевой сессии
</Button>
```

Стрелка включена у `primary` по умолчанию. Для действия без стрелки передай
`showArrow={false}`. Вариант `tertiary` будет добавлен после утверждения его
визуального референса.
