# DialogueBubble

Реплики персонажей и обучающего режима. Варианты: `compact` (короткая фраза),
`wide` (обычная реплика), `story` (длинный текст / несколько абзацев),
`waiting` (три анимированные точки). Примеры доступны в Storybook.

Текст использует `--font-family-dialogue` (Clacon2 из `assets/fonts/clacon2.ttf`),
имя — `--font-family-heading`. Цвета берутся из общих дизайн-токенов.
Рамка с двойным контуром, ромбом и хвостом реализована SVG, не растровой картинкой.

`animated` включает набор текста (по умолчанию). При смене `text` набор начинается
заново; «Показать сразу» раскрывает реплику, не переключая шаг. Полный текст
резервирует высоту и доступен скринридеру без побуквенных объявлений.
При `prefers-reduced-motion` реплика отображается сразу, точки не анимируются.

Навигация задаётся `onPrevious`, `onNext`, `onClose`; счётчик — `step` / `total`.
Компонент не управляет маршрутом или персонажем. `GuideArrow` — отдельная SVG-стрелка
с viewport-координатами `from` / `to`. Демо с Виззом находится в `pages/dev/guide`.
