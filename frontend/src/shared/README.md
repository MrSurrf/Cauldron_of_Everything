# Shared

Общий инфраструктурный слой без предметной логики.

- `styles/` — дизайн-токены, глобальные темы и базовые стили.
- `ui/` — будущие универсальные UI-компоненты.
- `api/` — будущий общий HTTP-клиент.
- `config/` — конфигурация окружения.
- `lib/` — универсальные утилиты.

Инструменты могут зависеть от `shared`, но `shared` не должен зависеть от
инструментов, workspace или предметных сущностей.
