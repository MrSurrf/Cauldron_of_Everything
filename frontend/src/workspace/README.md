# Workspace

Платформенный слой будущего плиточного рабочего пространства.

- `contracts/` описывает сериализуемые контракты инструментов и плиток.
- Будущая `model/` будет отвечать за раскладку и пользовательские настройки.
- Будущая `registry/` будет связывать манифесты инструментов с их runtime UI.
- Будущая `ui/` будет содержать сетку, оболочку и состояния плиток.

Workspace не должен импортировать внутренние файлы инструментов. Сохранённая
раскладка хранит только идентификаторы, геометрию, настройки и версию схемы.
