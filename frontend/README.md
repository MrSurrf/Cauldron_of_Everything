# Frontend

Эта папка — полностью зона фронтенд-разработчика. Клади сюда весь свой код
и ресурсы, бэкенд сюда не лезет.

```
frontend/
├── assets/        # иконки, фоны, шрифты и прочие ресурсы
│   ├── icons/
│   ├── backgrounds/
│   └── fonts/
└── ...            # твой код (React/Vue/что угодно)
```

## Что нужно знать о бэкенде

- Документация API (Swagger): **http://127.0.0.1:8000/api/docs/** — попроси
  бэкендера запустить сервер (`python manage.py runserver` в папке `backend/`).
- Авторизация — JWT: логин → `access`/`refresh` токены, дальше заголовок
  `Authorization: Bearer <access>`.
- CORS уже настроен для `localhost:3000` и `localhost:5173`. Если твой
  dev-сервер на другом порту — скажи бэкендеру, он добавит.
- Полное описание эндпоинтов и флоу — в корневом `README.md`.
