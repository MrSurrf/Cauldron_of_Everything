# Frontend

Эта папка — зона фронтенд-разработчика. Фронтенд построен как модульный монолит.

```text
src/
├── app/          # корневая оболочка и глобальные стили
├── pages/        # тонкие точки входа URL
├── workspace/    # плиточная платформа
├── tools/        # автономные сложные инструменты
├── entities/     # общие предметные сущности
└── shared/       # дизайн-токены, UI и инфраструктура
```

Текущий рабочий опросник изолирован в `src/tools/survey/`, его публичные
изображения — в `public/tools/survey/`. Подробные правила находятся в
`src/ARCHITECTURE.md`.

## Что нужно знать о бэкенде

- Документация API (Swagger): **http://127.0.0.1:8000/api/docs/** — попроси
  бэкендера запустить сервер (`python manage.py runserver` в папке `backend/`).
- Авторизация — JWT: логин → `access`/`refresh` токены, дальше заголовок
  `Authorization: Bearer <access>`.
- CORS уже настроен для `localhost:3000` и `localhost:5173`. Если твой
  dev-сервер на другом порту — скажи бэкендеру, он добавит.
- Полное описание эндпоинтов и флоу — в корневом `README.md`.
